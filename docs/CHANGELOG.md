# Version history

## v0.2.12
- Keep the dashboard awake while idle and allow normal power-button and cover sleep.

## v0.2.11
- Show the complete Kindle battery percentage, including 100%, beside its icon.

## v0.2.10
- Hide internal heartbeat messages from conversation cards.
- Preserve CPU history across restarts and keep chart columns evenly spaced.
- Refreshes update the current minute; missing minutes stay empty.
- Sample CPU usage correctly on the collector thread.

## v0.2.9
- Four conversation cards per page, with one title line and up to three reply lines.
- A compact right-aligned weather block beside the clock.
- Aligned system metrics and simplified cards without repeated footer status.

## v0.2.8
- LaTeX formulas in questions and replies: inline math, fractions, roots, matrices, sums and integrals.
- Formula-aware spacing keeps complete formulas within each conversation card.
- The Mac preview renders formulas locally, including when offline.
- Optional keep-awake mode disables idle sleep while preserving power-button and cover sleep.

## v0.2.7
- Native drawing reduces Mac memory use during and between dashboard updates.
- Large conversation histories use a bounded memory cache.
- Stopping the dashboard also closes its drawing processes.

## v0.2.6
- Automatic updates at the start of every minute.
- A Refresh button fetches current conversations, metrics and weather.
- Manual updates preserve the next minute-aligned update.

## v0.2.5
- Sleep using the power button or cover.
- Wake restores the dashboard and reconnects Bluetooth.
- Replies end on complete text lines.

## v0.2.4
- A single page shows the three latest conversations.
- The dashboard returns to the foreground after native home opens.
- Native brightness and warm-light controls remain available.

## v0.2.3
- Dashboard startup continues after USB storage becomes available.

## v0.2.1
- Chinese and English download editions with the interface language preconfigured.
